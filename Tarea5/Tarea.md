# Tarea Herencia

## Que es la herencia


La herencia en Java es un principio fundamental de la Programación Orientada a Objetos (POO) que permite que una clase herede los atributos y métodos de otra clase. Su principal objetivo es facilitar la reutilización de código y establecer relaciones jerárquicas entre clases


## Que es una clase Abstracta

Una clase abstracta es una clase que no se puede instanciar directamente (no puedes crear objetos con new ClaseAbstracta()) y sirve como una plantilla base para otras clases que heredan de ella. Su propósito principal es definir la estructura y el comportamiento común de una jerarquía de clases, dejando que las subclases completen los detalles específicos.


## Como es el uso de variables heredas

El uso de variables heredadas (o atributos heredados) consiste en acceder y manipular las variables definidas en una clase padre (superclase) desde una clase hija (subclase) a través del mecanismo de herencia.

Su propósito principal es definir la estructura y el comportamiento común de una jerarquía de clases, dejando que las subclases completen los detalles específicos.
