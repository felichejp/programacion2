# Criterios de Aceptación - Sesión 08

- [x] **Sin números mágicos:** Todas las dimensiones y valores por defecto están en `Configuracion`.
- [x] **Configuracion:** Tiene constructor privado y miembros `public static final`.
- [x] **Ancho de pantalla:** Se encuentra únicamente en `Configuracion.ANCHO_PANTALLA`.
- [x] **Contador estático:** Implementado en `Player.getContadorJugadores()`.
- [x] **Estructura de paquetes:** Organizado en `Juego`, `Juego.config` y `Juego.entidad`.
- [x] **Experimento Paso 6:** Presionar las teclas solo afecta al jugador asociado porque cada player (`1, 2 y 3`) apunta a una instancia independiente en la memoria, mover el estado (`x`, `y`) de una instancia no altera las variables del resto.
